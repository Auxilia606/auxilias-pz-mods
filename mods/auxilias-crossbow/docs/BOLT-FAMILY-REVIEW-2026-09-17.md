# 볼트·파손·장전 모델 후속 정리 — 2026-09-17

## 변경 내용

9월 16일 개선된 Blender 원본에 이어 볼트 계열을 직접 편집했다. 석궁 몸체를
재생성하지 않았고, 저장한 `.blend`가 계속 편집 원본이다.

- 금속/돌 볼트: 가늘게 다듬은 목제 자루, 얇은 깃 윤곽, 굴곡이 있는 결속끈.
  금속촉은 좁은 목과 사각 단면으로 정리하고 돌촉은 얇은 가장자리와 박리면을 추가.
- 아래쪽 깃 2장을 조금 위로 돌리고 촉이 넓어지는 위치를 앞몸통 밖으로 옮겨
  장전 홈과 앞몸통의 겹침을 제거. 3종 × 2재료의 장전 모델에 공통 반영.
- 부러진 볼트 2종: 정상 볼트의 약 65% 길이인 앞쪽 조각. 정상 볼트와 동일한
  자루 굵기와 촉 메시를 사용하며, 별도 막대 형태의 파편 대신 자루 자체에
  불규칙한 V형 파손면을 만듦. 깃과 뒤쪽 노크는 남기지 않음.
- 볼트 자루·금속촉·돌촉 3종: 정상 볼트에서 연결 복사한 전용 모델 추가.
  기존 아이템의 StaticModel/WorldStaticModel을 새 모델에 연결하여
  SmallHandle/Nails/ChippedStone 대용 모델을 교체.
- 정상 볼트에도 StaticModel을 지정해 소품 모델 참조를 완성.

기존 아이템·레시피·모드 ID, 탄약 선택과 발사 Lua, 아이콘, 재료 아틀라스는
유지했다. 원래 있던 장전 전/후 상태 전환을 그대로 사용한다. 버전은 0.2.0이다.

## 검사 결과

- Blender 5.2.0 LTS에서 총 16개 FBX 내보내기/재가져오기 통과.
- 각각 메시·재질·UV 레이어 1개, 면적이 0인 기하/UV 삼각형 없음.
- 삼각형 위치·방향·UV 오차 0.000001 이내, 내보내기 전후 원본 해시 동일.
- 기존 9개 석궁 상태의 몸체·활대·시위 등 393개 부품에 대해 수정 전후
  정점·면·UV·변환이 정확히 같음을 비교. 이전 본체 개선을 보존했다.
- 정상/장전 볼트 크기 일치, 이동만 적용, 기존 시위 접촉면과 끝 돌출 유지.
- 장전 홈/앞몸통 여유: 금속 약 0.258 mm, 돌 약 0.225–0.288 mm.
  앞몸통 끝을 가로지르는 촉 모서리도 검사한다. 허용 하한은 0.15 mm다.
- 파손/제작 부품의 공유 메시와 크기 검사 추가. 임시 메모리에서 촉 연결을
  끊거나 깃을 홈 안으로 내리면 검사기가 거부하는 것을 확인했다.
- 9개 석궁 상태의 사선·위·옆·정면과 7개 소형 자산의 사선 렌더 확인.
- 루트 `tools/validate.ps1`로 등록된 3개 모드 검사 통과.
- `tools/package.ps1 -Mod auxilias-crossbow`로 로컬 후보 ZIP과 체크섬 생성,
  패키지 항목별 경로·크기·SHA-256 감사 통과.

검사 이미지와 `report.json`은 `../work/model-validation/`, 수정 전 백업과
부품 보존/거부 검사 결과는 `../work/bolt-refinement/`에 있다.
전체 비교 이미지: `../work/model-validation/bolt-family-review.png`.
