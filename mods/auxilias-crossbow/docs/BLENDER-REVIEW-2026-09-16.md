# 석궁 3종 Blender 직접 편집 — 2026-09-16

## 작업 범위

기존 `.blend` 메시를 직접 분리·편집했다. 새 모델을 만드는 생성기는 실행하지
않았으며, 편집한 `.blend`와 그 안에 패킹한 텍스처가 작업 원본이다.
`generate_assets.py`는 원본을 다시 만드는 기능을 제거하고 내보내기 도구로
연결되는 호환 진입점으로 바꿨다.

- 경량: 뒤쪽 몸통을 더 가늘게 깎고 아래쪽을 다듬어 목제 석궁의 인상을 강화.
- 일반: 공통 몸통의 곡면과 옆면 나뭇결을 다듬고 어두운 활대·보강부와 대비.
- 중량: 짙은 목재와 어두운 강철, 절제된 가장자리 마모로 재료 차이를 강조.
- 9개 석궁 상태의 공통 부품은 연결된 메시로 유지하고, 장전 볼트는 바닥에
  놓이는 볼트와 실제 메시 데이터를 공유. 활대·시위의 기존 측정 좌표는 보존.
- 앞쪽 결속부의 평가 메시를 단순화. 원본에는 편집 가능한 모디파이어를 유지.
- 모든 표면 방향에 맞는 UV를 배치하고, 공용 아틀라스를 128px에서 512px로 변경.
  공용 볼트 4종도 형상은 유지하면서 UV를 같은 재질 영역에 다시 배치.
- 원본의 0면적 활대 삼각형 48개를 정리. 조명은 키 100 W / 필 45 W / 노출 0.

## 자동 검사

- Blender 5.2.0 LTS로 13개 FBX를 내보낸 뒤 다시 가져오기 통과.
- 메시 하나, 재질 하나, UV 레이어 하나 유지.
- 삼각형별 위치·감기는 방향·UV를 허용 오차 0.000001 이내로 비교.
- 장전/바닥 볼트의 메시 공유, 이동만 적용, 크기 일치, 시위 접촉과 27–33 mm
  볼트 끝 돌출 범위 확인.
- 내보내기 전후 `.blend` SHA-256 동일. 패킹한 아틀라스·외부 원본 PNG·배포 PNG 일치.
- 예전 생성기 진입점의 `--verify-only --no-render`도 원본을 변경하지 않고 통과.
- 임시 메모리에서 장전 볼트 확대, 한 상태의 몸통 이동, 활대 정점 이동,
  UV 전체 붕괴를 각각 주입했을 때 검사기가 모두 거부하는 것을 확인.
- 루트 `tools/validate.ps1`: 등록된 모드 3종 통과.
- `tools/package.ps1 -Mod auxilias-crossbow`로 로컬 검사 ZIP 생성. 배포 트리의
  모든 파일과 ZIP 항목의 경로·크기·SHA-256 일치. 버전은 0.2.0을 유지하며
  Workshop에 게시하지 않았다.

현재 비교 렌더와 기계 판독 보고서는 `../work/model-validation/`에 있다.
`three-crossbows-review.png`는 금속 장전 사선·석제 장전 평면·96px 표시 비교다.
이 렌더의 조명은 게임 화면을 재현하지 않는다.
