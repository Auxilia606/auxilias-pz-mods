# 편의성 기능

## 일반 차량 분해

운행 가능한 차가 더는 필요하지 않을 때 차량을 월드에서 깔끔하게 치우는 기능이다. 대상은 `Burnt`/`Smashed` 폐차가 아닌 일반 승용 차량이다. 기존 폐차 분해 기능은 그대로 둔다. 대상 게임 버전은 저장소의 `config/project-zomboid.json`을 따른다.

### 사용 조건과 결과

- 용접 토치에 10회 사용량이 남아 있고 용접 마스크를 갖춘 플레이어만 분해할 수 있다.
- 차량의 적재 공간에 아이템이 있어도 분해할 수 있다. 실린 동물과 탑승자가 없어야 하며, 견인하거나 견인되는 중인 차량과 엔진이 켜진 차량은 분해할 수 없다.
- 실행 전 확인 대화상자는 **보관함의 아이템은 바닥에 떨어지고 장착된 부품과 연료는 차량과 함께 소모되며 되돌릴 수 없다**고 알린다. 확인을 취소하면 아무것도 소모하거나 옮기지 않는다.
- 분해가 완료되면 모든 차량 부품 보관함의 아이템을 차량 주변 바닥에 떨어뜨리고, 용접 토치 사용량 10회를 소모한 뒤 차량을 제거한다. 회수품과 경험치는 현재 바닐라 폐차 분해 규칙을 사용한다. 장착된 부품과 연료는 별도로 회수하지 않는다.

### 검증 항목

정적 검사는 실제 게임 동작의 증거가 아니다. 다음 항목을 코드와 배포 파일에서 확인한다.

- 컨텍스트 메뉴와 작업 코드가 일반 차량만 대상으로 삼고 `Burnt`/`Smashed` 폐차를 가로채지 않는지 확인한다.
- 토치 10회 사용량, 용접 마스크, 동물·탑승자 부재, 견인 관계와 엔진 상태를 작업 시작 및 완료 시 다시 확인하고, 적재 공간의 아이템을 차단 조건으로 사용하지 않는지 확인한다.
- 취소 또는 중단 시 차량·토치·보관함 내용물이 유지되는지, 완료 시 모든 차량 부품 보관함의 아이템을 바닥으로 옮긴 뒤 바닐라 폐차의 회수품·경험치 경로와 차량 제거가 연결되는지 확인한다.
- 영어·한국어 메뉴 및 확인 대화상자 번역 키가 존재하고 배포 트리에 포함되는지 확인한다.
- `./tools/validate.ps1 -Mod auxilias-qol`과 전체 `./tools/validate.ps1`을 통과하는지 확인한다.

사용자가 로컬 배포된 0.2.1의 분해와 아이템 드롭이 동작한다고 보고했다. 기록된 범위와 미확인 조건은 `SMOKE-TEST.md`에 구분했다. 다음은 상세한 재현 결과가 아직 없는 추가 테스트 계획이다.

- 여러 차량 부품 보관함에 종류와 수량이 다른 아이템을 넣은 일반 승용 차량에서 메뉴 표시, 확인, 작업 완료, 모든 아이템의 바닥 드롭(누락·중복 없음), 차량 제거, 회수품 및 경험치, 토치 10회 소모를 확인한다.
- `Burnt`/`Smashed` 폐차에서 기존 바닐라 분해 메뉴가 유지되는지 확인한다.
- 토치 사용량 부족, 마스크 없음, 동물·탑승자 존재, 견인 관계, 엔진 가동 상태에서 분해가 차단되는지 각각 확인한다. 적재물만 있는 경우에는 차단되지 않아야 한다.
- 확인 취소와 작업 중단, 작업 도중 조건 변화가 차량·보관함 내용물·자원을 변경하지 않는지 확인한다.
- 분해 전후 저장·불러오기와 재접속 후 차량·바닥에 떨어진 아이템·회수품 상태를 확인한다. 멀티플레이에서는 모든 참여자에게 같은 결과가 보이는지도 확인한다.

### 재료 보상 개선안 (아직 미적용)

현재 일반 차량은 폐차와 같은 재료·용접 경험치를 준다. 다음 변경에서는 기존 폐차 보상 규칙은 그대로 두고, 일반 차량에만 **판금 1개, 고철 1개, 추가 재료 1개**를 더하는 안을 제안한다. 추가 재료는 전자부품 고철 50%, 타이어 조각 30%, 고무 호스 20% 확률로 고른다. 이 재료들은 설치된 대상 빌드에 존재하지만 폐차 기본 보상표에는 없다. 차량 보관함에서 바닥으로 옮긴 기존 아이템은 이 3개 보상에 포함하지 않는다.

설치된 42.20.4 폐차 보상표는 용접 레벨이 높아질수록 반복 추첨 횟수가 늘어난다. 그 추첨 횟수나 확률 자체를 올리면 고레벨 보상이 크게 불어나므로, 고정 3개를 더하는 편이 증가량을 통제하기 쉽다. 실제 장착 부품 회수는 상태·충전량과 멀티플레이 동기화를 별도로 검증한 뒤 결정한다.
