  모든 근접무기 책이 10/8/6/4/2 가중치를 갖는지 확인했다.

  장검을 가진 추가 소품 목록에도 정확히 해당 권만 들어가는지 확인했다.
- 55권의 독서·서버 완료 배율 검사는 그대로 통과했다. 실제 월드 생성 빈도 및
  게임 내 XP·저장·MP 검증은 별도이며 기존 저장의 책을 제거하는 마이그레이션은 없다.

## 2026-09-29 — AuxiliasQoL 0.4.0 이동·근접 무기 스킬북

- 설치된 게임은 42.21.0으로 업데이트되었다. 이번 Lua 검사는 이 설치본의 실제 바닐라 소스와 Kahlua로 실행했다.

  재독 비중첩·독자별 진도 분리 및 서버 완료 경로를 전체 55권에 검사했다.

  신규 채집 정의 55개에서 모든 시리즈의 등록·가중치·반복 병합 비중복을 확인했다.

  배율 처리는 기존 바닐라 작업을 그대로 사용하며 별도 XP 지급 코드는 없다.

  캐릭터·아이템·네트워크·채집 등록 API는 시험 대역을 사용한다.
