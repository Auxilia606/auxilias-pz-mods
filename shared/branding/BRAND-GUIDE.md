# Auxilia Workshop 비주얼 가이드

## 브랜드 인상

Auxilia 모드의 대표 이미지는 “어두운 작업대 위에 놓인, 목적이 분명한 생존 도구”처럼
보여야 한다. 과장된 효과보다 읽기 쉬운 실루엣, 절제된 재료색, 한 군데의 녹슨 주황색
포인트를 반복해 동일 제작자의 작업이라는 인상을 만든다.

## 고정 규격

- 원본 캔버스: 1254×1254 PNG 이상, 정사각형
- 배포 출력: 512×512 PNG
- 출력 위치: Workshop 루트의 `preview.png`, 모드 루트와 버전 폴더의 `poster.png`와
  `icon.png`
- 다섯 출력 파일은 픽셀 차이가 없는 동일 파일
- 가장자리 8%는 카드 크롭과 UI 오버레이를 고려한 안전영역
- 주 피사체 실루엣은 캔버스 너비의 58–76%

정확한 값과 팔레트는 `brand.json`이 기계가 읽는 단일 기준이다.

## 반복할 시각 언어

- 배경은 `#242424`에서 `#333333`으로 이어지는 약한 중앙 조명만 사용한다.
- 주 피사체는 밝은 회색·바랜 목재·검게 단조한 금속을 중심으로 두고, 핵심 상호작용
  지점 한 곳에 `#D95F20` 포인트를 둔다.
- 3/4 시점과 부드러운 상단 좌측 키라이트를 기본으로 하며, 바닥 그림자는 흐리고 짧게 둔다.
- 작은 카드에서도 기능을 알아볼 수 있도록 부품보다 전체 실루엣을 먼저 읽히게 한다.
- 제목과 기능 목록은 Workshop 페이지 텍스트에 맡긴다. 썸네일에는 작은 글자를 넣지 않는다.
- 피사체마다 카메라 거리와 조명을 바꾸지 말고 Blender 공통 프리셋을 재사용한다.

## 제작과 검수

1. 모드의 `source-assets/workshop`에 고해상도 원본을 저장한다.
2. `thumbnail-template.svg`의 배경과 안전영역을 참고해 피사체를 배치하고, 내보내기 전
   `guides` 그룹을 숨긴다.
3. 512×512로 한 번만 축소하고 다섯 배포 위치에 같은 PNG를 복사한다. 버전별
   `mod.info`가 선택되면 대표 이미지 경로도 그 버전 폴더를 기준으로 해석되므로,
   `poster.png`와 `icon.png`를 반드시 해당 `mod.info` 옆에 둔다.
4. `tools/sync-workshop-art.ps1`이 만드는 128px, 64px, 32px 미리보기에서 실루엣과
   주황색 포인트가 즉시 구분되는지 확인한다. 실제 모드 목록에 가까운 32px 검수를
   최종 합격 기준에 포함한다.
5. `./tools/validate.ps1 -Mod <slug>`로 크기, 파일 동일성, 원본 존재 여부를 검사한다.

Crossbow와 Ammunition은 같은 어두운 생존자 작업대, 좌상단의 부드러운 조명, 낡은 목재와
검게 단조한 금속, 한 군데의 주황색 포인트를 공유한다. 주 피사체만 석궁 또는 탄약 제작
도구로 바꾸어 같은 제작자의 시리즈임을 유지한다.
향후 개선은 이 규칙 자체를 먼저 갱신한 뒤 모든 모드에 같은 릴리스 단위로 적용한다.
